# CodeAlpha Task 2: Unemployment Analysis with Python

## 📊 Project Overview
This project analyzes the impact of Covid-19 on unemployment in India using Python Data Analysis.

**Internship:** CodeAlpha Data Analytics Internship
**Task:** 2
**Author:** Rakshitha R

## 🎯 Objective
- Analyze unemployment trends in India
- Understand Covid-19 impact on jobs
- Visualize data for insights
- Compare Rural vs Urban, Region wise

## 📁 Dataset
- Source: Kaggle - Unemployment in India
- File: Unemployment in India.csv
- Contains: Date, Region, Area (Rural/Urban), Unemployment Rate, etc.

## 🔧 Tools Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook / Google Colab

## 📈 Analysis Performed
1. Data Cleaning & Preprocessing
2. Unemployment Rate Over Time (Trend Analysis)
3. Covid-19 Impact - Before vs After Lockdown
4. Region wise Unemployment Analysis
5. Rural vs Urban Comparison
6. Seasonal Trends (Month wise)

## 💡 Key Insights
- Unemployment spiked sharply after March 2020 lockdown
- Urban areas were more affected than Rural areas
- Some regions like Haryana, Rajasthan showed higher rates
- Lockdown caused ~3x increase in unemployment
